## Starting point and authority

The original ABC is refuted. The [rank-two counterexample](../../proof/arithmetic-realization-counterexample.md)
uses

$$
A_1=\begin{pmatrix}1&1\\0&5\end{pmatrix},\qquad
A_2=\begin{pmatrix}1&2\\0&5\end{pmatrix}.
$$

Both have labeled subset ranks $(0,1,1,2)$ and multiplicities
$(1,1,1,5)$ in the declared ambient lattice $\mathbb Z^2$.
Modulo $5$, the cut line of $A_a$ is generated by $(1,a)$; this vector
is a cycle precisely when $1+a^2=0$. Therefore

$$
\operatorname{Bic}_5(A_1)=0,\qquad
\operatorname{Bic}_5(A_2)\cong\mathbb Z/5.
$$

The family occurs in Lenz's Example 3 [LENZ]. The bicycle calculation has
its separate repository proof; no novelty priority is asserted here.
The discrepancy also occurs at modulus $10$. At modulus $25$ both groups
have order five, so checking a single order can miss the tower obstruction.
Even every subset's abstract quotient-group isomorphism class agrees.
Merely replacing multiplicities with those abstract groups does not repair
unrestricted invariance.

The graph and regular TU results have separate proved records.
The [surjective theorem](../../proof/surjective-realization-invariance.md),
merged in PR #6, now proves realization invariance and the Gram-torsion
description for essential free-lattice realizations with $m(E)=1$.
Surjectivity is additional to torsion-freeness $m(\emptyset)=1$.
Representation uniqueness in that domain is established prior art [PP].
It is a settled baseline here, not the next open target.

The live [claim registry](../../proof/claims.toml) is theorem authority.
This brief, its question queue, and its experiment are exposition and
exploration. No open question below is promoted by a finite run. Historical
questions in papers require a fresh status audit before being advertised
as currently unsolved; this document does not certify the absence of later
solutions.

## Connections

| Field | Exact connection | Research boundary |
| --- | --- | --- |
| Arithmetic representation theory | Integer representations modulo unimodular row changes and column signs; signed Hermite forms and representation enumeration [LENZ, PP]. | Classify tower variation among genuinely inequivalent nonsurjective realizations, preserving complete arithmetic data. |
| Coding theory over finite rings | The bicycle is the Euclidean hull of the row-generated code [HULL]. | Determine the extra data controlling hulls over $\mathbb Z/p^k$ and their transition maps. |
| Toric arrangements | Arithmetic data record less than some intersection and cohomological structures [PAG]. | Audit the published arithmetic-independence-poset question [PP] and test whether enriched lattice data clarify it. |
| Graph Jacobians and arithmetic geometry | Critical groups carry a monodromy pairing; realization with a specified pairing is a separate problem [JAC]. | Study pairing transport and restricted graph realizability without equating a group with a group equipped with pairing. |
| Integral topology | Cellular cut/flow lattices and higher critical groups have torsion-(co)homology correction terms [CELL]. | Formulate the appropriate modular exact sequence before claiming an extension of the graph theorem. |
| Matroids over rings and valuation geometry | Quotient modules provide a framework richer than arithmetic multiplicities [RING]. | Identify sufficient embedded lattices, maps, or pairings; abstract subset modules alone fail on the existing pair. |

## ABC-HULL-01: establish the code-hull interface

For $R=\mathbb Z/n$ and $C=\operatorname{im}(A^T:R^r\to R^E)$,
use the standard coordinate pairing $\langle x,y\rangle=\sum_e x_e y_e$.
For an edge vector $x$,

$$
x\in C^\perp
\iff y^T A x=0\text{ for every }y\in R^r
\iff A x=0.
$$

The last implication tests the coordinate unit potentials and uses no
division or field-rank argument. Consequently
$C\cap C^\perp=\operatorname{Bic}_n(A)$ for composite moduli as well.
Here $\mathbb Z/p^k$ is a ring, not the field with $p^k$ elements.
[HULL] supplies the hull terminology and a finite-chain-ring research
setting; its cyclic-code results are not imported for arbitrary row codes.

First deliverable: specify this bridge, signed-coordinate equivariance,
reduction and scaled inflation for the code-hull tower. The seed experiment
checks literal dot products against every codeword, the existing potential
implementation, and the independent edge/lattice oracle. An unrestricted
general linear change of edge coordinates need not preserve the pairing;
do not use it as an allowed code equivalence without transporting the form.

## ABC-RD-01: classify nonsurjective realization dependence

Main question: which explicit extra lattice data determine the compatible
tower, and when is it constant across all realizations of one arithmetic
matroid? Compare representations only after exact all-subset equality.

Start with the finite family
$A_{a,b}=\left(\begin{smallmatrix}1&a\\0&b\end{smallmatrix}\right)$
for $b\ge2$ and $\gcd(a,b)=1$ [LENZ]. The checked-in seed covers only
$b=5$, $a=1,2$; expanding a bound requires an explicit new scope and receipt.
Use the general representation algorithm [PP] for a later systematic
enumeration rather than treating an entry box as all representations.

Required evidence includes prime, prime-power, and mixed composite moduli;
annihilator profiles; both modulus maps; the original discrepant pair;
and positive surjective and rank-one controls. A conjectured sufficient
invariant must survive the equal-subset-quotient negative control.
Search failure is finite evidence, not a proof of sufficiency.

## ABC-MODULE-01: specify the added data

Candidate inputs include a row lattice embedded in $\mathbb Z^E$ with its
coordinate pairing, or a diagram retaining compatible lattice maps [RING].
These are candidates, not claims of minimality. State which ambient and
coordinate transformations preserve each proposed object, then derive
the induced maps over every modulus. Explicitly distinguish a sufficient
description from a minimal or representation-independent description.

The seed checks the full Smith factors of every column subset of the
index-five pair. They agree despite the hull discrepancy. It therefore
rules out the coarse object consisting only of subset quotient-group
isomorphism classes; it does not rule out diagrams carrying additional
maps or embeddings.

## ABC-TORIC-01: audit the topology reconstruction questions

[PP] asks whether the arithmetic independence poset of a toric arrangement
is determined by its arithmetic matroid. [PAG] asks whether the integral
cohomology algebra of the complement determines the central toric
arrangement. Both are published questions; their current status is an
explicit source-audit task. Known negative results about the reverse
direction must not be called open: arithmetic data do not in general
determine rational cohomology, and the layer poset does not in general
determine integral cohomology [PAG].

First action: search subsequent primary literature, record the exact
equivalence notions, and extract source-pinned integer matrices. Only
then compare their arithmetic signatures and hull towers. Do not infer
topology from a hull-order match or mismatch.

## ABC-JAC-01: pairings and graph realization

[JAC] studies finite abelian groups with specified symmetric pairings as
graph Jacobians, including partial results for even-order pairings and
obstructions for simple graphs. Audit subsequent progress before selecting
a remaining subproblem. General graph realization and simple-graph
realization are distinct domains.

First local task: write an exact pairing interface on the already proved
graph/Gram side and check transport with explicit orientation and label
witnesses. The abstract torsion-group tower does not by itself assert
recovery of the monodromy pairing. Claims about graph reconstruction,
pairing recovery, or cryptographic hardness need separate statements.

## ABC-CELL-01: torsion-corrected cellular extension

[CELL] establishes higher-dimensional cut/flow and discriminant-group
relationships with torsion corrections. First transcribe its exact
sequences and hypotheses. Then test small integer boundary matrices with
both torsion-free and torsion homology, retaining the adjacent boundary
map and verifying the chain condition. A single matrix does not encode a
whole cellular chain complex. Any proposed modular sequence must explain
the failure of the unrestricted finite-group torsion model already seen
for $A=[2]$.

## Run the starting experiment

```sh
python conformance/check_research_program.py
python experiments/realization_dependence.py --check
```

Six explicit realizations cover the counterexample, the scalar-two torsion
obstruction, two surjective controls without a unit column basis, and rank
zero. The fixture names every matrix, modulus, and expected order.
The receipt records complete edge sets, annihilator profiles, reduction
and scaled-inflation images, and Chinese-remainder checks where the listed
moduli allow them. Enumeration has no silent cap; this is a small-fixture
starting experiment, not a census or an efficient general algorithm.

Regenerate with `--write` only after investigating intentional source or
fixture changes. The next work is the explicit interface and enriched
data specification above; optional topology tracks do not block it.
